# Yaser Girit

### Data Science & Advanced Analytics

I build data products that turn messy information into clear, auditable decisions.

My focus is on **advanced analytics, machine learning, experimentation, data quality, and decision-support systems**—from exploratory analysis to deployable applications.

- Based in Istanbul, Türkiye
- Interested in Data Science, Applied ML, Decision Intelligence, and Analytics Engineering
- Building portfolio projects with reproducible evaluation and business context

## What I work on

- **Predictive modeling:** classification, ranking, calibration, and evaluation
- **Advanced analytics:** EDA, cohort and segmentation analysis, statistical reasoning, and visualization
- **Decision systems:** turning model outputs into capacity- and value-aware recommendations
- **Data quality:** validation, schema contracts, reproducible datasets, and leakage-aware workflows
- **Applied AI:** evidence-bound LLM decision support and ML/LLM evaluation

## Featured projects

### [Bank Campaign Decision Engine](https://github.com/yasergirit/bank-campaign-decision-engine)

A decision-system portfolio project for bank marketing data.

- Leakage-aware feature design and frozen train/validation/test assignments
- Model selection with auditable artifacts and environment provenance
- Campaign ranking under capacity and expected-value constraints
- SQL/Python feature-parity checks across 41,188 source rows
- Delivered with PostgreSQL, FastAPI, Streamlit, and Docker

### [AI-Assisted Fraud Detection](https://github.com/yasergirit/AI_Assisted_Fraud_Detection)

A Streamlit case study comparing ML metrics with evidence-bound LLM decision support.

- Focused on imbalanced fraud-detection evaluation
- Separates classifier selection from LLM-assisted interpretation
- Uses supplied evidence instead of inventing data or metrics

### [Data Science Job Salaries](https://github.com/yasergirit/ds-job-salaries)

An exploratory data-analysis project on data-science compensation.

- Salary, experience level, remote-work, company location, and company-size analysis
- Visualization work using Seaborn

## How I approach analytics

```text
Question → Data validation → Exploratory analysis → Evaluation design
        → Model / insight → Decision rule → Clear communication
```

I care about more than model scores: a useful analysis should be reproducible, understandable, and connected to the decision it supports.
